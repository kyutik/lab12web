Команди Git

Створення репозиторію

Створити локальний репозиторій
git init [project name]
Клонувати наявний репозиторій
git clone my_url

Перегляд репозиторію

Показати стан файлів
git status
Показати незбережені в індексі зміни
git diff
Показати зміни в індексі
git diff --cached
Показати зміни відносно останнього коміту
git diff HEAD
Порівняти два коміти
git diff commit1 commit2
Показати авторів і коміти для рядків файла
git blame [file]
Показати версію файла в коміті
git show [commit]:[file]
Показати історію комітів
git log
Показати історію шляху зі змінами
git log -p [file/directory]

Робота з гілками

Показати локальні гілки
git branch
Показати локальні та віддалені гілки
git branch -av
Перейти на гілку
git checkout my_branch
Створити гілку
git branch new_branch
Видалити об’єднану локальну гілку
git branch -d my_branch
Перейти на гілку призначення
git checkout branch_b
Об’єднати branch_a з поточною гілкою
git merge branch_a
Позначити поточний коміт тегом
git tag my_tag

Внесення змін

Додати файл до індексу
git add [file]
Додати зміни в поточній папці до індексу
git add .
Зафіксувати зміни з індексу
git commit -m "commit message"
Зафіксувати зміни відстежуваних файлів
git commit -am "commit message"
Прибрати файл з індексу, зберігши зміни
git reset [file]
Відкинути незакомічені зміни відстежуваних файлів
git reset --hard
